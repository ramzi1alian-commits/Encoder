# Secure Keyboard (مشروع Android — Kotlin)

كيبورد بديل لأندرويد مصمم بثلاث حمايات:

1. **بدون إنترنت نهائيا** — الـ `AndroidManifest.xml` لا يحتوي إطلاقا على
   `android.permission.INTERNET`. هذا ليس وعدا في الكود، بل قيد يفرضه نظام
   أندرويد نفسه على مستوى الـ sandbox: أي تطبيق بدون هذه الصلاحية لا يستطيع
   فتح اتصال شبكة إطلاقا، حتى لو كان فيه كود معطوب أو ثغرة.

2. **لا يخزن ولا يسجل أي شيء تكتبه** — في `SecureInputMethodService.kt`, كل
   ضغطة زر بتتبعت مباشرة للحقل اللي انت بتكتب فيه عن طريق
   `InputConnection.commitText()`, ومفيش أي متغير أو ملف أو قاعدة بيانات
   بتحتفظ بتاريخ الكتابة.

3. **يمنع لقطات الشاشة** أثناء استخدام الكيبورد، عن طريق
   `WindowManager.LayoutParams.FLAG_SECURE`.

## التعديلات والإصلاحات اللي اتعملت (آخر مراجعة)

- **إصلاح رموز الكيبورد**: الخط كان بيستخدم `Typeface.SERIF`/`MONOSPACE` العامين،
  واللي على أجهزة كتير (خصوصا MIUI) مفيهمش غطاء لحروف عربية، فكانت الحروف
  بتظهر كرموز/مربعات. اتصلح بالاعتماد على نفس عائلة الخط الافتراضية للنظام
  (اللي دايما بتدعم العربي) مع تغيير النمط (bold/italic) بس بدل تبديل العائلة.
- **إصلاح الثيم/الألوان**: كل شاشة كانت بتلوّن زرارين بس وتنسى الباقي، وشاشة
  اختيار الألوان نفسها ما كانتش بتتلوّن خالص ولا بتوضح اللون المختار حاليا.
  اتعمل مركزيًا (`ThemeUtil`) وبقى كل زرار وكل بطاقة لون بتوضح حالتها.
- **إصلاح الوضع الليلي/النهاري**: مكانش فيه مجلد `values-night/` أصلا، فالتطبيق
  كان بنفس الشكل الغامق مهما اخترت. دلوقتي فيه مجموعة ألوان فاتحة حقيقية
  للوضع النهاري.
- **استبدال PBKDF2 بـ Argon2id** (64MB ذاكرة / 3 مرات تكرار) — أقوى بكتير ضد
  هجمات GPU/ASIC لأنه بيكلّف ذاكرة حقيقية لكل محاولة، مش بس وقت معالجة.
  **مهم**: النصوص المشفّرة بالنسخة القديمة (PBKDF2) مش هتتفك بالنسخة دي والعكس،
  عمدا، عشان مفيش رجوع صامت للطريقة الأضعف.
- **زرار "توليد مفتاح عشوائي قوي"** في شاشة التشفير — بيولّد مفتاح عشوائي
  حقيقي (مش كلمة سر بتفكرها إنت) بصيغة Base32 سهلة النقل يدويا، بدل الاعتماد
  على باسورد قابل للتخمين.
- **تصفير المفتاح وكلمة السر من الذاكرة** بعد الاستخدام مباشرة (`clearPassword()`
  + `Arrays.fill`)، بدل ما تفضل في الـ heap لحد الـ garbage collector.
- **تفعيل R8/ProGuard** في نسخة الـ release (`minifyEnabled true`) بدل ما كانت متوقفة.
- **منع حفظ حقول النص/المفتاح الحساسة** في `onSaveInstanceState` (`saveEnabled="false"`)
  ومنع الـ autofill عليها.

- **حد أدنى إجباري لقوة المفتاح (128 بت إنتروبيا تقديرية)** — التطبيق دلوقتي
  **يرفض** يشفّر بمفتاح ضعيف، مش بس بينصح. فيه مؤشر حي تحت خانة المفتاح
  بيوريك التقدير وأنت بتكتب. **مهم**: التقدير ده مبني على تنوع الحروف
  والطول (charset x length)، ومبيقدرش يكتشف كلمة قاموس طويلة بس متوقعة
  (زي "Password123456789!") — الضمان الرياضي الحقيقي الوحيد هو زرار
  "توليد مفتاح عشوائي قوي".

## حدود مهمة لازم تعرفها (بصراحة)

- **منع لقطة الشاشة** بيشتغل بس على واجهات أندرويد الرسمية (زرار
  Screenshot، تطبيقات التسجيل العادية). **مش هيمنع** حد يصور الشاشة
  بموبايل تاني، ولا هيشتغل بشكل مضمون على أجهزة معمول لها Root بسوفتوير
  نظام معدّل.
- **التطبيق اللي بتكتب فيه** (واتساب، تويتر، أي حاجة) هيستقبل النص اللي
  بتكتبه بشكل طبيعي — كده أي كيبورد بيشتغل أصلا. الكيبورد ده بيضمن إن
  **هو نفسه** مش بيضيف أي تجميع أو تخزين أو إرسال لأي حاجة تكتبها، مش إن
  التطبيق التاني هيبقى أعمى عن النص.
- لسه مشروع أساسي (MVP) — لوحة مفاتيح عربية بسيطة، من غير أرقام أو رموز
  أو دعم إنجليزي. ممكن تضيفهم بسهولة.
- **مهم جدا: التعديلات دي بترفع مستوى الأمان الهندسي للمشروع، لكنها
  ما بتخليهوش "معتمد للاستخدام العسكري".** التصنيف ده مش رقم تكرار
  أو سطر كود بيرفعه — بيحتاج منظومة كاملة: مفاتيح مخزنة في هاردوير معتمد
  (HSM/StrongBox) بدل الاعتماد على باسورد المستخدم، وحدات تشفير مصدّقة
  رسميا (FIPS 140-2/3)، ومراجعة أمنية مستقلة كاملة للكود، وسلسلة توريد
  وتوقيع موثوقة (مش نسخة Debug من GitHub Actions). المشروع ده أساس جيد
  للخصوصية الشخصية اليومية، مش بديل لمنظومة معتمدة رسميا.
- **نسخة الـ Debug من GitHub Actions موقّعة بمفتاح Debug عام معروف** — أي حد
  يقدر يبني نسخة تشبهها بالظبط ويوقّعها بنفس الطريقة. لأي استخدام فيه بيانات
  حساسة فعلا، لازم تعمل نسخة Release موقّعة بمفتاح خاص بيك إنت (Android
  Studio: Build > Generate Signed Bundle/APK)، ومتشاركش ملف الـ keystore
  مع حد.

## إزاي تبنيه

1. حمّل [Android Studio](https://developer.android.com/studio)
2. افتح المجلد ده كمشروع (`Open an existing project`)
3. سيبه يعمل Gradle sync
4. وصّل موبايل أندرويد بالـ USB (فعّل USB debugging) أو استخدم إيميوليتور
5. دوس Run ▶

## إزاي تفعّله بعد التثبيت

1. افتح التطبيق، دوس "تفعيل الكيبورد من الإعدادات"
2. فعّل "Secure Keyboard" من قائمة لوحات المفاتيح
3. ارجع للتطبيق ودوس "تبديل الكيبورد الحالي" واختاره

## ملاحظة مهمة قبل استخدام GitHub Actions

ملف `.github/workflows/build.yml` بيستخدم أمر `./gradlew` عشان يبني الـ APK
تلقائيًا على GitHub. الملف ده (`gradlew` + `gradlew.bat` + ملف jar الخاص
بيه) مش موجود في هذا الزيب لأنه بيتولد تلقائيًا. **قبل ما ترفع المشروع
على GitHub**، افتحه مرة واحدة في Android Studio (أو شغّل الأمر
`gradle wrapper` من التيرمينال لو عندك Gradle مثبت) — هيتولد الملف
تلقائيًا، وبعدين ارفعه مع باقي الكود.

## إزاي تستخدم GitHub Actions

1. ارفع المشروع (repository) على GitHub بما فيه مجلد `.github/workflows/`
2. روح تبويب **Actions** في صفحة الـ repo، هتلاقي الـ workflow بيشتغل
   تلقائيًا مع كل رفع كود جديد على فرع `main`
3. بعد ما يخلص (حوالي 2-3 دقايق)، افتح الـ run، وهتلاقي **Artifacts**
   في الأسفل فيها ملف `secure-keyboard-debug-apk` — نزّله وثبّته على
   موبايلك مباشرة


```
app/src/main/java/com/securekeyboard/app/
  SecureInputMethodService.kt   ← الكيبورد نفسه
  SettingsActivity.kt           ← شاشة التفعيل
app/src/main/res/
  xml/method.xml                ← وصف الـ IME للنظام
  values/strings.xml
app/src/main/AndroidManifest.xml  ← لاحظ: لا توجد صلاحية INTERNET إطلاقا
```
